# dev-js

Repositório criado para as aulas de front-end com JS e conceitos básicos de desenvolvimento web.
Aqui ficam exercícios, pequenos projetos e testes de funcionalidadws usadas no dia a dia do desenvolvimento front-end.

## Objetivo
Este repositório serve como um ambiente de estudo e prática, focado em:
- Manipulação de arrays em JavaScript
- Manipulação do DOM
- Desenvolvimento com React
- Organização de projetos front-end

## Tecnologias utilizadas
- HTML
- JavaScript
- REACT
- DOM
- Git e GitHub

 ## Aprendizado
- Fundamentos do JavaScript
- Conceitos de React
- Organização de código
- Boas práticas de desenvolvimento
